一、为什么优先推荐 ClashParty 客户端？

虽然市面上存在诸如 Clash Verge、Clash for Windows 等传统工具，但 ClashParty 作为专为新时代网络生态定制的图形化内核套件，具备三大核心技术优势：

  1. 内置 Meta (Mihomo) 最新核心：原生完整支持 Vless、XTLS-Reality、Trojan、Hysteria2、TUIC 等下一代高性能传输协议，抗封锁能力远超市面老旧客户端。
  2. 更智能的 TUN 虚拟网卡模式：一键全局接管宿主机全协议流量，不仅完美支持浏览器外网访问，连没有自带代理设置的终端命令行（Git/SSH）、海外桌面应用（Slack/Discord）和外服端游均可无缝加速。
  3. 优雅的规则分流与策略组管理：可自动识别国内流量直接直连（Direct），海外流量（Proxy）智能走自由猫稳定节点，AI专线（OpenAI/Claude）定向走住宅原生IP，既省流量又保隐私。

二、ClashParty 订阅导入实操四步法

无论您使用的是 Windows 操作系统还是 macOS，ClashParty 的配置流程均高度统一，只需遵循以下四个标准动作：

步骤 1：下载并安装 ClashParty 客户端

进入自由猫后台的“使用文档与客户端下载”专区，选择对应您系统版本的安装包。安装完成后首次启动程序，建议允许通过系统防火墙访问权限。

步骤 2：在自由猫后台一键复制订阅链接

登录 自由猫官网（freecatcloud.homes） 用户控制台，找到您已购买的套餐卡片（例如“自由猫·破晓套餐”），点击“复制订阅地址”或下拉选择“导入到 ClashParty”。

步骤 3：在 ClashParty 中拉取节点配置

打开 ClashParty 客户端主界面，点击左侧菜单栏的 订阅管理 (Profiles)，将刚刚复制的专属订阅 URL 粘贴到输入框中，点击 下载 / 更新 (Download)。客户端将自动与自由猫高速 API 握手，数十个涵盖香港、日本、新加坡、美国、台湾等优质专线节点即刻同步展示完毕。

步骤 4：选择代理模式与启动系统代理

切换至客户端左侧的 代理 (Proxies) 页面：

  • 运行模式推荐选择 Rule (规则模式)，国内百度、微信、淘宝直连不耗流量，海外 Google、YouTube、GitHub 自动走自由猫海外专线；
  • 在策略组中，将“节点选择”设为您期望的地区（如“香港01”用于4K秒开，或“美国01”用于访问 OpenAI 生成式大模型）；
  • 最后在首页开启 系统代理 (System Proxy) 开关即可！
